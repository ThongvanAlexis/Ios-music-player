## Artifacts this phase produces

All are NEW: AppCopy owns all exact Copywriting Contract literals/templates from the first screen. LibraryStore.swift declares TrackSnapshot {id, filename, relativeLocator, metadata, readiness}, FileRevision {resourceIdentity, byteLength, modificationDate}, TransferReadiness {pending, validating, ready, failed} and TransferObservation {locator, revisionBefore, revisionAfter, declaredContainerLength, parserOutcome, observedAt}; these exist before any view/decoder uses them. MusicPlayerApp composes LibraryStore, PlaybackCoordinator and SkinLoader; FilesView consumes TrackSnapshot and sends select(trackID:). LibraryStore owns a versioned programmatic NSManagedObjectModel and background context, storing TrackRecord {id: UUID, relativeLocator: String, revision: FileRevision, readiness: TransferReadiness, durationMilliseconds: Int64?}; no managed object crosses isolation. PlaybackCoordinator owns one AVAudioEngine/player and immutable PlaybackSnapshot {trackID, filename, state, positionMilliseconds, durationMilliseconds, generation, requiresExplicitPlay}. AppConfiguration centralizes bufferFrameCapacity=4096, maximumScheduledBufferCount=4, preparationTimeoutSeconds=15, seekTimeoutSeconds=10, scanQuietIntervalSeconds=2 and diagnostics limits; quiet time is never a completion proof. build_config.json owns project, scheme, bundleIdentifier=com.oliver.musicplayer, deploymentTarget=17.0, xcodeVersion=26.6, xcodeBuild=17F113, developerDirectory, artifactName=musicplayer-ios-unsigned-ipa, IPA basename, runner=macos-26, command timeout and packaging paths. Schema formats are versioned before first user data; this is an app-owned initial format, not a published interchange.
